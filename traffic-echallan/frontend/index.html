Live camera capture

Uses your device's actual camera through the browser — works for a laptop webcam or a phone camera (open this page on your phone's browser). For a real installed IP/CCTV camera, see the note below instead — those connect on the server side, not through the browser.

Connecting a real IP / CCTV camera

A real installed CCTV camera streams over RTSP, which browsers can't connect to directly — it needs a small script running on the server instead. This project includes one: 

cd backend
python camera_worker.py --source "rtsp://user:pass@192.168.1.50:554/stream1" --camera-id 1 --interval 5

Replace the RTSP URL with your camera's actual stream address (check its manual — Hikvision, Dahua, and generic ONVIF cameras all use slightly different URL formats). Violations it detects will show up in the Violations Review tab automatically, same as everything else.
